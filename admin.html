PayPay URL 更新

初回のみ、下の「アクセストークン」欄にGitHubの個人用アクセストークンを入力してください(次回以降はこの端末に保存され不要です)。

アクセストークンの作り方(初回のみ)

1. GitHub → 右上アイコン → Settings → 一番下 Developer settings
2. Personal access tokens → Fine-grained tokens → Generate new token
3. Repository access で「coffee-payment」のみ選択
4. Permissions → Contents を「Read and write」に設定
5. 発行されたトークン(ghp_で始まる文字列)をコピーし、上の欄に貼り付け
